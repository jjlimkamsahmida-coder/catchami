# Catchami art assets — two batches

All files are PNGs using the Catchami palette and a consistent chibi game-art direction.

## Batch 1: Keeper and PvP
- keeper.png — 1024x1024, RGBA
- keeper_poses.png — 1024x1024, 2x2 RGBA pose sheet
- bubble_launcher.png — 1536x512, 3 frames horizontally, RGBA
- bubble_effects.png — 1536x1024, 3x2 RGBA VFX sheet
- arena_landscape.png — 1920x1080, opaque
- arena_portrait.png — 1080x1920, opaque
- ui_bits.png — 1536x1024, 3x2 RGBA sprite sheet

## Batch 2: World and onboarding
- gates_signs.png — 1536x1024, 3x2 RGBA sprite sheet
- handoff.png — 1024x1024, RGBA
- gift.png — 1024x1024, RGBA
- paw_village.png — 1600x600, opaque
- whispering_forest.png — 1600x600, opaque
- mining_valley.png — 1600x600, opaque

## Notes
The character, cannon, and effects were generated as illustrated concept art on a faux-checkerboard image; backgrounds were programmatically made transparent where possible. Manually inspect any light edges before shipping; some tiny bright details may need cleanup.
UI elements, props and the 3 area banners are extracted from a generated atlas. The area banners were upscaled from smaller originals, so treat them as development placeholders rather than final production-resolution art.
A sprite-sheet cell is an independent image frame, not an animation sequence with intrinsic frame data.
No actual game code is included.
